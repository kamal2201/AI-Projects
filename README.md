# AI-Projects

A collection of AI systems, agents, and generative UI applications.

---

## Projects

### 1. [CanvasAI](./CanvasAI)
An adaptive conversational AI inspired by ChatGPT's Intelligent UI. Unifies text generation and 19 interactive React components (charts, calculators, sortable tables, Mermaid diagrams, regression playgrounds, and KPI metrics) into **one continuous conversation feed with real-time SSE streaming**.
- **Stack**: FastAPI, LangChain, Google Gemini, React 19, TypeScript, Tailwind CSS, Vite.

### 2. [Customer Support Agent with Mem0](./Customer%20Support%20Agent%20with%20Mem0)
A multi-tier banking customer support agent with persistent customer memory and retrieval-augmented generation (RAG).
- **Stack**: FastAPI, LangChain, Mem0, ChromaDB, SQLite, Docker.

### 3. [Transformer](./Transformer)
PyTorch transformer model implementation, helper training routines, and architecture experiments.
- **Stack**: PyTorch, Python, Jupyter.
